### Nosso Software Bíblico

O [Graphe](https://github.com/claudioscheer/graphe) é nosso aplicativo desktop de estudo bíblico (Windows, Linux e macOS): gratuito, código aberto (MIT), com painéis divididos, números de Strong, referências cruzadas, comentários, dicionários e conversão de módulos theWord e MySword para MyBible SQLite3.
